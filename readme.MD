# Mátrix szorzó

Két mátrix szorzását elvégző, és bemutató program, state pattern (állapot minta) segítségével. Lehetőség van automata és manuális módszerrel is használni a programot.

## Használata

Klónozás után nyissuk meg a mappát egy IDE-ben, majd a terminálban adjuk ki a parancsot:

```bash
npm install
```

A docs mappában található a State Machine vizuálisan bemutatva, draw.io segítségével. Használatához töltsük le a hediet.vscode-drawio bővítményt Visual Studio Code-ban. Telepítés után elég megnyitni a fájlt.

## Indítás

A program indítható development, és production módban. Development módban a mátrixok szorzása soronként megjelenik a konzolon, production módban csak a végeredmény kerül megjelenítésre.

Development mód:

```bash
npm run dev
```

Production mód:

```bash
npm run production
```
